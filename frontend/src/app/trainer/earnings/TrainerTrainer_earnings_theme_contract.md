# 🎨 TRAINER EARNINGS THEME CONTRACT

The Trainer Earnings module depends on the following CSS variables defined in `globals.css`:

- `--bg-page`: Page background
- `--bg-card`: Card background
- `--bg-header`: Table/List header backgrounds
- `--bg-input`: Input field backgrounds
- `--border`: Standard border color
- `--foreground`: Primary text color
- `--secondary`: Subtext color
- `--primary`, `--primary-subtle`: Brand color and its subtle background variant
- `--success`: Positive KPI metrics (e.g. Total Earnings) and Settled status
- `--warning`: Pending metrics and Pending status
- `--info`: Action metrics (e.g. Sessions Completed) and Processing status
- `--danger`: Error banners
- `--skeleton-base`, `--skeleton-highlight`: Skeleton loader animation colors
