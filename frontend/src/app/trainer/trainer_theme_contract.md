# Trainer Theme Contract

The Trainer module follows the Smart Gym 360 global design system. Required surface tokens: `--bg-page`, `--bg-card`, `--bg-floating`, `--bg-overlay`, `--bg-popover`, `--bg-sidebar`, `--bg-header`, `--bg-input`, `--border`, `--border-focus`. Typography tokens: `--text-primary`, `--text-secondary`, `--text-disabled`. Semantic tokens: `--primary`, `--primary-hover`, `--primary-subtle`, `--success`, `--warning`, `--danger`, `--info`, `--purple`. Payment tokens: `--pay-cash`, `--pay-upi`, `--pay-card`, `--pay-bank`. Loading tokens: `--skeleton-base`, `--skeleton-highlight`.

Use named Tailwind tokens mapped from these variables; do not use raw hex or arbitrary color values in Trainer JSX.
