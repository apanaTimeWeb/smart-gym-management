# Superadmin White-labeling — Theme Contract

- **Surfaces**: `bg-page`, `bg-card`, `bg-floating`
- **Text**: `text-primary`, `text-secondary`, `text-tertiary`
- **Borders**: `border-border`
- **Actions**: `bg-primary`, `text-on-primary`
- **Status Colors**:
  - Active: `text-success` / `bg-success-bg`
  - Pending: `text-warning` / `bg-warning-bg`
  - Failed/Error: `text-danger` / `bg-danger-bg`
- **Animation**: All transitions must be prefixed with `motion-safe:`.
