# Superadmin Gym Detail Theme Contract

This sub-feature consumes the global semantic tokens already required by the `gyms` module.

## Consumed Tokens
- `--bg-page` / `bg-page`
- `--bg-card` / `bg-card`
- `--bg-input` / `bg-input`
- `--text-primary` / `text-primary`
- `--text-secondary` / `text-secondary`
- `--text-disabled` / `text-disabled`
- `--border` / `border-border`
- `--primary` / `bg-primary` / `text-primary`
- `--success-bg` / `bg-success-bg`
- `--success-text` / `text-success`
- `--warning-bg` / `bg-warning-bg`
- `--warning-text` / `text-warning`
- `--danger-bg` / `bg-danger-bg`
- `--danger-text` / `text-danger`
- `--focus-ring` / `ring-primary`
- `--shadow-card` / `shadow-card`
- `--shadow-dialog` / `shadow-dialog`

The sub-feature must not introduce raw colors or arbitrary Tailwind values.
