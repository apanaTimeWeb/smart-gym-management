# Superadmin Messaging WhatsApp Theme Contract

This sub-feature uses the global semantic theme tokens consumed by the parent Messaging module.

## Consumed Tokens
- `bg-page`, `bg-card`, `bg-input`, `bg-overlay`
- `text-primary`, `text-secondary`, `text-disabled`, `text-on-primary`
- `border-border`, `ring-primary`
- `bg-primary`, `bg-primary-hover`
- `bg-success-bg`, `text-success`
- `bg-warning-bg`, `text-warning`
- `bg-danger-bg`, `text-danger`
- `bg-info`, `text-info` where the feature uses informational state UI
- `shadow-card`, `shadow-dialog`, `shadow-popover`

External WhatsApp brand color treatment must remain native and must not be folded into configurable ERP status tokens.
