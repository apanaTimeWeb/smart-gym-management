# Analytics Theme Contract

This file lists the CSS custom variables consumed directly by the `analytics` feature.
As per Rule 57, all colors and spacing must use these variables.

## Consumed Variables
- `--background`
- `--foreground`
- `--card`
- `--card-foreground`
- `--primary`
- `--primary-foreground`
- `--border`
- `--input`
- `--ring`

## Typography
- `--font-sans`

This contract ensures that if this module is ported to another Next.js application, these variables must be provided in the global CSS.
