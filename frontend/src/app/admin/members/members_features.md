# Admin Members Module — Features

## What this module does
The Admin Members module allows gym administrators to manage the complete lifecycle of gym memberships.

## Features
- View all gym members with KPI stats (Total, Active, Pending, Expired)
- Search members by name or phone number
- Filter by membership status (Active / Pending / Expired)
- Add new members with full profile capture (name, phone, email, Aadhaar, gender, billing cycle, plan)
- Edit existing member details
- Renew member subscriptions (via AdminRenewModal)
- Record pending payments (via AdminAddPaymentModal)
- View detailed member profile (Overview, Attendance, Payments tabs)
- Delete members with double-confirmation (pessimistic UI via AdminConfirmModal)
