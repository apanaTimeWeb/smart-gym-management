# Campaigns — Theme Contract

This module consumes only global semantic tokens defined by the global design system:

- `--primary`, `--primary-hover`, `--primary-subtle`
- `--bg-page`, `--bg-card`, `--bg-input`, `--bg-overlay`
- `--border`, `--border-focus`
- `--text-primary`, `--text-secondary`, `--text-on-primary`, `--text-on-danger`
- `--success-bg`, `--success-text`
- `--warning-bg`, `--warning-text`
- `--danger-bg`, `--danger-text`
- `--skeleton-base`
- `--focus-ring`
- `--shadow-card`, `--shadow-dialog`

No business-specific colors are defined here. Business statuses remain owned by the feature.
