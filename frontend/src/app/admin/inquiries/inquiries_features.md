# Admin Inquiries Module — Features
- Lead KPI stats: Total, New, Follow-Up, Converted
- Track leads from Facebook, Instagram, Website, Google, Walk-In, Referral
- Inline status update (New ? Follow Up ? Converted ? Closed)
- Add / Edit inquiry with source, interest, notes, follow-up date
- Delete with confirm
- Search by name or phone
- "Convert to Member" quick-action for converted leads
