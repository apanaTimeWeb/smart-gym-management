# Admin Settings — Theme Contract

## Layout & Backgrounds
- `--bg-background` (Page background)
- `--bg-card` (Main card containers)
- `--bg-input` (Form inputs, toggles, sub-cards)
- `--bg-input-hover` (Hover states)
- `--border` (Borders and dividers)

## Typography
- `--text-foreground` (Primary text, headings)
- `--text-secondary` (Subtext, labels, descriptions)
- `--text-disabled` (Disabled input text)

## Interactive & Semantic
- `--primary` (Active tabs, save buttons, focused inputs, active toggles, primary badges)
- `--primary-hover` (Hover state for save button)
- `--primary-subtle` (Subtle backgrounds for active elements)
- `--success` (Success icons, toggles, success badges)
- `--success-bg` (Success badge backgrounds)
- `--danger` (Delete buttons, error texts, danger badges)
- `--danger-bg` (Danger backgrounds)
- `--warning` (Warning texts)
- `--info` (Info texts)

## Shadows & Elevations
- Standard shadow utilities applied directly via Tailwind `shadow-sm`, `shadow-md`.
