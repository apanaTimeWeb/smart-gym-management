# PublicLanding Theme Contract

PublicLanding consumes the global Smart Gym 360 design system. No feature-specific global tokens are defined.

## Semantic colors
- `--primary`, `--primary-hover`, `--primary-subtle`
- `--text-primary`, `--text-secondary`, `--text-disabled`, `--text-on-primary`, `--text-on-warning`, `--text-on-danger`, `--text-on-success`
- `--success`, `--success-bg`, `--success-text`
- `--warning`, `--warning-bg`, `--warning-text`
- `--danger`, `--danger-bg`, `--danger-text`
- `--info`, `--info-bg`, `--info-text`
- `--purple-bg`, `--purple-text`

## Surfaces / borders / elevation
- `--bg-page`, `--bg-card`, `--bg-input`, `--bg-header-translucent`, `--bg-overlay`, `--surface-hover`, `--surface-highlight`, `--surface-zebra`, `--overlay-backdrop`, `--border`, `--border-focus`, `--focus-ring`
- `--shadow-card`, `--shadow-dialog`

## Radius / motion / typography
- `--radius-md`, `--radius-lg`, `--radius-xl`, `--radius-full`
- `duration-fast`, `duration-base`, `duration-slow`
- Inter font family and default 14px body scale inherited from global system

## Justified local visual tokens
- Native official social-brand colors are retained exactly for external brand links, as required by the design system.
- Hero overlay/CTA visual aliases depend on global semantic tokens and only exist inside the PublicLanding stylesheet.
- Print-mode black/white overrides are limited to the documented print requirement.

## Not used
No chart tokens, payment tokens, context-menu surfaces, drag/drop colors, density-mode tokens, or status-badge registry are owned by this module.
