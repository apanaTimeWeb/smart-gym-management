# Admin Layout — Theme Contract

The shell consumes only approved global semantic tokens and zero-business interaction patterns.

## Consumed tokens
- `bg-header`
- `bg-sidebar`
- `bg-input`
- `bg-popover`
- `bg-overlay`
- `bg-primary`
- `bg-primary-hover`
- `text-primary`
- `text-secondary`
- `text-on-primary`
- `border-border`
- `focus-ring`
- approved motion/focus tokens from the global design system

No raw color literals or arbitrary Tailwind values are permitted.
