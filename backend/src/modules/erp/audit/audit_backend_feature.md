# ERP Audit Module

## Overview
This module handles the retrieval and creation of audit logs for the ERP system. It follows the micro-feature structure.

## Folder Structure
- `controllers/`: Contains `audit-log-retrieval.controller.ts`.
- `services/`: Contains micro-services for finding and creating audit logs.
- `entities/`: Contains the `audit-log.entity.ts`.
- `audit.repository.ts`: Isolated database query layer.
