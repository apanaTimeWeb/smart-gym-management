# TypeORM Migrations

This directory holds all database migrations generated by TypeORM CLI.

## Commands

```bash
# Generate a new migration (detects schema changes vs. entities)
npm run migration:generate -- src/database/migrations/InitialSchema

# Run all pending migrations
npm run migration:run

# Revert the last migration
npm run migration:revert

# Show migration status
npm run migration:show
```

## Notes

- `synchronize: false` is set in the DataSource config — migrations are the only way to apply schema changes.
- Never delete migration files once they have been run against production.
- Always generate migrations AFTER changing your `*.entity.ts` files.
